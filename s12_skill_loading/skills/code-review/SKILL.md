# 代码审查

先明确用户指定的文件或变更范围。审查未提交修改时，读取 Git Diff；审查指定文件时直接读取该文件。只按调用关系补读相关代码。

优先检查行为错误、边界条件、异常处理和数据保存。每个发现给出文件位置、触发条件及影响；区分确定的问题与需要验证的疑点。没有发现问题时直接说明，并交代尚未验证的部分。

本技能用于只读审查。用户明确要求修复或运行测试时，再执行对应操作；不要因审查任务创建临时脚本或修改文件。
