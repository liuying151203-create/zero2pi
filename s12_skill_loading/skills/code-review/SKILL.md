# 代码审查

先明确用户指定的文件或变更范围。审查未提交修改时，读取 Git Diff；审查指定方法时，用 grep 在指定文件中定位方法行号，再用 read_file 的 start_line、limit 读取目标范围，不反复读取整个文件。只为验证具体疑点，按调用关系补读相关代码；不要顺带扫描 Git 历史、运行环境或整个仓库（尤其 .venv）。

优先检查行为错误、边界条件、异常处理和数据保存。每个发现给出文件位置、触发条件及影响；区分确定的问题与需要验证的疑点。没有发现问题时直接说明，并交代尚未验证的部分。

本技能用于只读审查。用户明确要求修复或运行测试时，再执行对应操作；不要因审查任务创建临时脚本或修改文件。

信息足够就给出结论；无法验证的疑点说明缺少什么证据，不为了找出问题无限搜索。工具被拒绝后不要换等价命令重试。
